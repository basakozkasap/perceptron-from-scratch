# Perceptron From Scratch

## About This Project

This project is a simple perceptron implementation in Python, developed as part of my learning process in artificial neural networks.

The code was developed with AI assistance for educational purposes.

## Features

- Configurable number of inputs
- Custom initial weights
- Adjustable learning rate
- Bias and threshold parameters
- Automatic weight updates
- Training results and final predictions

## Technologies

- Python
- Google Colab

## Purpose

To understand how a perceptron learns through weight updates without using machine learning libraries.
